# LeafGreen `AgbMain` reconstruction

The Japanese release `bpg-j-rev0-retail` is the origin reference. All 7 cataloged releases (Japanese, English, German, French, Italian, Spanish) were followed from the GBA ARM entry branch through the literal-backed ARM-to-Thumb bootstrap transition into `AgbMain`. The observed builds form 4 explicit structural variant(s); each release is checked against its variant's direct-call name sequence, call offsets, target equivalence and edge-kind shape, plus one backward main-loop branch, and no return. Per-release maps preserve addresses, code hashes, calls, entry-chain evidence, and raw-free control-flow summaries. No ROM instruction bytes are published. Symbol names remain based on `pret/pokefirered` at `037335f4c725d7c9aecdac87066f2002b4bd7e14`, `src/main.c`.
