# LeafGreen MapMusicMain reconstruction

The Japanese release `bpg-j-rev0-retail` is the origin reference. All 7 cataloged releases (Japanese, English, German, French, Italian, Spanish) contain the adjacent 232-byte MapMusicMain state machine with eight jump-table cases. Cases 0, 2, 3 and 4 share the idle target; repeated PlayBGM, IsBGMStopped and IsFanfareTaskInactive targets agree inside every release. Per-release maps contain hashes, calls and raw-free control-flow summaries. No ROM instruction bytes are published. Naming is corroborated by `pret/pokefirered` at `037335f4c725d7c9aecdac87066f2002b4bd7e14`, `src/sound.c`.
